xiaozhi-4g dual

LCKFB SZPI ESP32-S3 with an ML307 module. Writes the full image at 0x0, build ....

  • Needs Chrome or Edge on desktop. Safari and Firefox cannot flash over USB.
  • Tick Erase device in the dialog: it clears NVS, so WiFi credentials, the activation code and the selected network type are reset.
  • If no port shows up, hold BOOT, plug the cable in, then release BOOT.
  • To read the serial log, connect and choose Logs & Console.
