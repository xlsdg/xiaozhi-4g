Command line notes

PORT is the serial device, for example /dev/ttyUSB0 on Linux or /dev/cu.usbserial-0001 on macOS. merged-binary.bin and the ZIP are attached to the latest release; this page only ships the newest build. On a board that will not boot, hold BOOT, plug the cable in, then release BOOT.
